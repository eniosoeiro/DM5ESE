# Identidade visual ES Medição — 0.20.0

Marca vetorial aplicada à interface nativa, ao ícone adaptativo e à abertura do Android.

- `es-medicao-logo-clara.svg`: logo escura para fundos claros.
- `es-medicao-logo-escura.svg`: logo branca para fundos escuros.
- `es-medicao-icone.svg`: ícone quadrado com cantos arredondados.

O símbolo combina as letras ES com marcações de medição. Não contém símbolo de marca registrada nem selo de certificação.

Paleta: azul profundo `#0B2D42`, verde de ação `#0F766E`, turquesa `#14B8A6`, texto `#133348`, texto secundário `#607586`, linhas `#DCE7EC` e fundo `#F3F7FA`.

Os SVGs usam texto editável com fonte de sistema. Nenhuma fonte é distribuída. A aplicação utiliza recursos vetoriais em `app/src/main/res/drawable/brand_mark_*` e ícones `ic_pro_*`, sem depender de um screenshot para desenhar controles.

Os exemplos ilustrativos aprovados orientaram a identidade. Bateria do instrumento, conexão ativa, usuário, clientes e medições não são simulados na interface instalada; o aplicativo apresenta dados disponíveis e estados reais.
